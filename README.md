# Muse CN · 安装包发布仓

这里是 **Muse CN**（中国版 Muse：一个 App，开箱即用操控你的电脑）的官方安装包发布仓。

- 本仓**只有安装包、版本信息和电脑底座的一键安装脚本，没有 App 源码**（源码在私有仓库里）。
- v0.2.0 起，电脑底座在电脑上贴一条命令安装：，装好后在 App「电脑」页输一次配对码即可。
- App 内的一键更新就是从这里取新版：它读取每个 Release 里的 `version.json` 判断有没有新版，再下载同 Release 的 `muse-cn.apk` 安装。

## 怎么装

1. 打开右侧 **Releases**，进最新版本。
2. 下载 `muse-cn.apk`。
3. 在手机上打开它安装（第一次装时，手机会问你允不允许安装，点允许即可）。

要求：Android 8.0 以上；不挑品牌与国产系统；不依赖谷歌服务。

装过旧版后，后续版本直接在 App 里点更新就行，不用再来这里下载。
